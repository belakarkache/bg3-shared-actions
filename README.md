# Shared Actions

Use potions, scrolls, special arrows and throwable items carried by anyone in your party, straight from your Action Bar. The mod adds four buttons, **Take Potion**, **Use Scroll**, **Quiver** and **Throw**, so you don't have to pass items between characters in the middle of a fight. **Quiver** needs a bow or crossbow equipped and lists only special arrows, since regular ammo is unlimited.

## Requirements

- [BG3 Script Extender](https://github.com/Norbyte/bg3se)

## Installation

1. **Back up your save.** The mod adds spells that are saved with your game.
2. Download the mod from [Nexus Mods](https://www.nexusmods.com/baldursgate3/mods/25804) or [GitHub Releases](https://github.com/belakarkache/bg3-shared-actions/releases).
3. In **BG3 Mod Manager**, import the `.zip`, enable **Shared Actions** and click **Export Load Order to Game**.
4. Start the game. The new buttons are on the Action Bar.
