# Shared Actions

*[English](#english) · [Português](#português)*

---

## English

Use potions, scrolls and throwable items carried by **anyone in your party**, straight from
your Action Bar. No more passing items around mid-fight. It also picks up potions and scrolls
added by other mods.

### Installing

1. You need [BG3 Script Extender](https://github.com/Norbyte/bg3se) installed.
2. **Back up your save.** The mod adds spells that are saved with your game.
3. Download `SharedActions.pak` from [Releases](../../releases).
4. Put it in `%LOCALAPPDATA%\Larian Studios\Baldur's Gate 3\Mods`, or add it with BG3 Mod Manager.
5. In **BG3 Mod Manager**, enable **Shared Actions** and click *Export Load Order to Game*.
6. Start the game. The new buttons are on the Action Bar.

## Português

Use poções, pergaminhos e itens arremessáveis de **qualquer pessoa do grupo** direto pela
Action Bar, sem ficar passando item de mochila em mochila no meio da luta. Também reconhece
poções e pergaminhos adicionados por outros mods.

### Instalação

1. É preciso ter o [BG3 Script Extender](https://github.com/Norbyte/bg3se) instalado.
2. **Faça backup do seu save.** O mod adiciona magias que ficam salvas no jogo.
3. Baixe o `SharedActions.pak` em [Releases](../../releases).
4. Coloque em `%LOCALAPPDATA%\Larian Studios\Baldur's Gate 3\Mods` ou adicione pelo BG3 Mod Manager.
5. No **BG3 Mod Manager**, ative o **Shared Actions** e clique em *Export Load Order to Game*.
6. Abra o jogo. Os botões novos ficam na Action Bar.
